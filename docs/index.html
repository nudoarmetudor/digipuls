What DigiPuls is

DigiPuls implements the Moldova Digital School Framework: a 19-indicator, 6-level, 4-domain integrated maturity model that schools self-assess against over a 2-year cycle, with a mandatory compliance floor (Order No. 675/2024) for network and device infrastructure. It replaces the Estonian "Oglinda Digitală" platform with a purpose-built instrument for Moldova, covering leadership, teaching & learning, human capacity, and infrastructure.

This is an MVP prototype — server-rendered Node.js/Express, no build step, SQLite for local dev, portable to Postgres for production. See the README for the honest list of what's built and what isn't.

A step-by-step process, not a questionnaire

A DigiPuls assessment cycle can take up to two weeks and involves multiple people — school leadership, teachers, the educational technologist, an external validator, meta-mentors. So the assessment is six independently-saveable steps, not one long form you must complete in order:

Not started

Nobody has opened this step yet.

In progress

Some, not all, indicators rated.

Needs attention

Rated, but evidence is missing for a Level 2+ score.

Every field autosaves the moment it's submitted. The only gate is final confirmation, which checks completeness and evidence — and if something's missing, it sends you right back to the review step with a clear inline message, not a dead end.

The maturity wheel

A concentric-circle, sectioned visualization: 19 wedges, one per indicator, grouped by domain. Ring distance from the centre is that indicator's level (0–5). It's plain server-rendered SVG — no chart library — and doubles as a coarser 4-sector "domain bands" view for the public tier.

Rendered entirely server-side in src/services/wheelChart.js.

Visibility, not automated matching

Every partner and project is different, and donation/support decisions are made case by case — so DigiPuls deliberately has no automated matching or scoring engine. Ministry and partner dashboards get filterable, sortable, CSV-exportable overviews of real school data (enrolment band, Order 675 compliance, per-domain scores). What you see is what the data actually says, with no ranking layered on top.

The one system-to-system integration DigiPuls keeps is the SIME onboarding seam: search a school in Moldova's national education-management system, review and edit the imported fields, then submit — import → check/validate → edit → submit, not a blind auto-fill.

Install it yourself

DigiPuls needs a running Node.js process and a database — this page is a static overview, not the live app. Clone the repository and run it locally or on your own server:

git clone https://github.com/<org>/digipuls.git
cd digipuls
npm run setup      # npm install + prisma migrate + seed demo data
npm run dev

Then open http://localhost:3000 — the login page lists every demo account (all use the password DigiPuls2026!).
